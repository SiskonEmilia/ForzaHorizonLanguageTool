# FH Language Combo Tool

Use different voice and text languages in Forza Horizon 5 / 6 (Steam, PC).

For example: Japanese voice + Chinese text, or English voice + Korean text.

**[Download Latest Release](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases)**

This is an unofficial tool, not affiliated with Playground Games, Turn 10 Studios, Xbox, or Microsoft. It only modifies local text resource files (`.zip` in `StringTables`). It does not touch executables, save files, network data, or anti-cheat components. All changes are backed up and fully reversible. Use at your own risk.
