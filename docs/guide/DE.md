# FH Language Combo Tool

Das FH Language Combo Tool ermöglicht es, in Forza Horizon 5 / 6 (Steam, PC) unterschiedliche Sprachen für Sprachausgabe und Text zu verwenden.

Zum Beispiel: deutscher Text + englische Sprachausgabe, oder deutscher Text + japanische Sprachausgabe.

## Download

Lade die neueste Version von der [Releases](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases)-Seite herunter.

- **Portable Version**: `FH-Language-Combo-Tool-Portable.exe` — direkt ausführbar, keine Installation nötig
- **Installer**: `FH-Language-Combo-Tool-Setup.exe` — installiert auf deinem System

## Schnellstart

1. Tool herunterladen und starten
2. Haftungsausschluss akzeptieren
3. Das Tool erkennt automatisch deine FH5/FH6 Steam-Installation
4. **Sprachausgabe** wählen — die Sprache, die du HÖREN möchtest (Charakterstimmen)
5. **Textsprache** wählen — die Sprache, die du SEHEN möchtest (Menüs, Untertitel)
6. Auf **Anwenden** klicken
7. Vorgang bestätigen
8. Spiel starten — fertig!

## Funktionsweise

Das Tool kopiert die Textsprache-Datei an die Position der Sprachausgabe-Datei im `StringTables`-Verzeichnis des Spiels und setzt die Startsprache des Spiels automatisch auf die gewählte Sprachausgabe-Sprache. Das Spiel lädt die Sprachausgabe aus einer Sprache, zeigt aber den Text einer anderen Sprache an.

## Wiederherstellen

Klicke jederzeit auf **Backup wiederherstellen**, um alle Änderungen rückgängig zu machen und den Originalzustand wiederherzustellen.

## Nach Spiel-Updates

Spiel-Updates können deine Sprachkonfiguration zurücksetzen. Falls das passiert, wende einfach die gleichen Einstellungen erneut an — das dauert nur Sekunden.

## Häufige Fragen

**F: Muss ich zuerst Sprachpakete in Steam herunterladen?**
A: Ja. Rechtsklick auf das Spiel in Steam → Eigenschaften → Sprache, und stelle sicher, dass sowohl die Sprach- als auch die Textsprache heruntergeladen sind.

**F: Ist das sicher?**
A: Das Tool ändert nur Textressourcen-Dateien (`.zip` in `StringTables`). Es berührt keine ausführbaren Dateien, Spielstände oder Anti-Cheat-Systeme. Alle Änderungen werden gesichert und sind rückgängig machbar.

**F: Werde ich gebannt?**
A: Dieses Tool verändert weder Gameplay noch Netzwerkdaten oder Anti-Cheat-Komponenten. Es ändert nur lokale Textdateien. Die Nutzung erfolgt jedoch auf eigenes Risiko.
