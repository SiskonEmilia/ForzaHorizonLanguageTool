# FH Language Combo Tool

FH Language Combo Tool later dig anvanda olika sprak for rost och text i Forza Horizon 5 / 6 (Steam, PC).

Till exempel: svensk text + engelsk rost, eller svensk text + japansk rost.

## Ladda ner

Ladda ner den senaste versionen fran [Releases](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases)-sidan.

- **Portabel**: `FH-Language-Combo-Tool-Portable.exe` — kor direkt, ingen installation kravs
- **Installationsprogram**: `FH-Language-Combo-Tool-Setup.exe` — installerar pa ditt system

## Snabbstart

1. Ladda ner och kor verktyget
2. Acceptera ansvarsfriskrivningen
3. Verktyget upptacker automatiskt din FH5/FH6 Steam-installation
4. Valj **Rostsprak** — spraket du vill HORA (karaktarsroster)
5. Valj **Textsprak** — spraket du vill SE (menyer, undertexter)
6. Klicka pa **Tillampa**
7. Bekrafta agerandet
8. Starta spelet — klart!

## Hur det fungerar

Verktyget kopierar textsprakfilen till rostsprakfilens position i spelets `StringTables`-katalog och staller automatiskt in spelets startsprak till det valda rostspraket. Spelet laddar rostljud fran ett sprak men visar text fran ett annat.

## Aterstallning

Klicka pa **Aterstall sakerhetskopiering** nar som helst for att angra alla andringar och atervanda till ursprungstillstandet.

## Efter speluppdateringar

Speluppdateringar kan aterstalla din sprakkonfiguration. Om detta hander, tillampas bara samma installningar igen — det tar bara nagra sekunder.

## Vanliga fragor

**F: Maste jag forst ladda ner sprakpaket i Steam?**
S: Ja. I Steam, hagerklicka pa spelet → Egenskaper → Sprak, och se till att bade rost- och textspraken ar nedladdade.

**F: Ar det sakert?**
S: Verktyget andrar bara textresursfiler (`.zip` i `StringTables`). Det ror inte korbara filer, sparfiler eller anti-fusk. Alla andringar sakerhetskopierasoch ar reversibla.

**F: Kommer jag att bli avstangd?**
S: Detta verktyg andrar inte gameplay, natverksdata eller anti-fusk-komponenter. Det andrar bara lokala textfiler. Anvandning sker dock pa egen risk.
