# FH Language Combo Tool

FH Language Combo Tool は、Forza Horizon 5 / 6（Steam、PC）で音声とテキストに異なる言語を使用できるツールです。

例：日本語テキスト＋英語音声、日本語テキスト＋韓国語音声。

## ダウンロード

最新バージョンは [Releases](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases) ページからダウンロードできます。

- **ポータブル版**: `FH-Language-Combo-Tool-Portable.exe` — インストール不要、直接実行可能
- **インストーラー版**: `FH-Language-Combo-Tool-Setup.exe` — システムにインストール

## クイックスタート

1. ツールをダウンロードして実行
2. 免責事項に同意
3. ツールが FH5/FH6 の Steam インストールを自動検出
4. **音声言語**を選択 — 聞きたい言語（キャラクターボイス）
5. **テキスト言語**を選択 — 表示したい言語（メニュー、字幕）
6. **適用**をクリック
7. 操作を確認
8. ゲームを起動 — 完了！

## 仕組み

ツールはゲームの `StringTables` ディレクトリ内で、テキスト言語ファイルを音声言語ファイルの位置にコピーし、ゲームの起動言語を選択した音声言語に自動設定します。ゲームは一方の言語から音声を読み込み、もう一方の言語でテキストを表示します。

## 復元

**バックアップを復元**をクリックすれば、いつでもすべての変更を元に戻し、元の状態に復元できます。

## ゲーム更新後

ゲームの更新により言語設定がリセットされることがあります。その場合は、同じ設定を再適用するだけです — 数秒で完了します。

## よくある質問

**Q: 事前に Steam で言語パックをダウンロードする必要がありますか？**
A: はい。Steam でゲームを右クリック → プロパティ → 言語で、音声言語とテキスト言語の両方がダウンロードされていることを確認してください。

**Q: 安全ですか？**
A: ツールはテキストリソースファイル（`StringTables` 内の `.zip`）のみを変更します。実行ファイル、セーブデータ、アンチチートには一切触れません。すべての変更はバックアップされ、元に戻せます。

**Q: BAN されますか？**
A: このツールはゲームプレイ、ネットワークデータ、アンチチートコンポーネントを変更しません。ローカルのテキストファイルのみを変更します。ただし、使用は自己責任でお願いします。
