# FH Language Combo Tool

FH Language Combo Tool 帮助你在 Forza Horizon 5 / 6（Steam，PC）中使用不同的语音和文字语言。

例如：简体中文文字 + 英语语音，或简体中文文字 + 日语语音。

## 下载

从 [Releases](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases) 页面下载最新版本。

- **便携版**: `FH-Language-Combo-Tool-Portable.exe` — 直接运行，无需安装
- **安装版**: `FH-Language-Combo-Tool-Setup.exe` — 安装到系统

## 快速开始

1. 下载并运行工具
2. 接受免责声明
3. 工具自动检测 FH5/FH6 的 Steam 安装路径
4. 选择**语音语言** — 你想要听到的语言（角色配音）
5. 选择**文字语言** — 你想要看到的语言（菜单、字幕）
6. 点击**应用**
7. 确认操作
8. 启动游戏 — 完成！

## 工作原理

工具将文字语言文件复制到游戏 `StringTables` 目录中语音语言文件的位置，然后自动将游戏启动语言设置为你选择的语音语言。游戏从一种语言加载语音音频，同时显示另一种语言的文字。

## 恢复

随时点击**恢复备份**即可撤销所有更改，恢复到原始状态。

## 游戏更新后

游戏更新可能会重置你的语言配置。如果发生这种情况，只需重新应用相同的设置 — 只需几秒钟。

## 常见问题

**问：需要先在 Steam 中下载语言包吗？**
答：是的。在 Steam 中右键游戏 → 属性 → 语言，确保语音和文字语言都已下载。

**问：安全吗？**
答：工具仅修改文字资源文件（`StringTables` 中的 `.zip`）。不会触及可执行文件、存档或反作弊系统。所有更改都会备份，可随时还原。

**问：会被封号吗？**
答：本工具不修改游戏玩法、网络数据或反作弊组件，仅更改本地文字文件。但使用风险自负。
