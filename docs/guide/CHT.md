# FH Language Combo Tool

FH Language Combo Tool 幫助你在 Forza Horizon 5 / 6（Steam，PC）中使用不同的語音和文字語言。

例如：繁體中文文字 + 英語語音，或繁體中文文字 + 日語語音。

## 下載

從 [Releases](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases) 頁面下載最新版本。

- **可攜版**: `FH-Language-Combo-Tool-Portable.exe` — 直接執行，無需安裝
- **安裝版**: `FH-Language-Combo-Tool-Setup.exe` — 安裝至系統

## 快速開始

1. 下載並執行工具
2. 接受免責聲明
3. 工具自動偵測 FH5/FH6 的 Steam 安裝路徑
4. 選擇**語音語言** — 你想要聽到的語言（角色配音）
5. 選擇**文字語言** — 你想要看到的語言（選單、字幕）
6. 點擊**套用**
7. 確認操作
8. 啟動遊戲 — 完成！

## 運作原理

工具將文字語言檔案複製到遊戲 `StringTables` 目錄中語音語言檔案的位置，然後自動將遊戲啟動語言設定為你選擇的語音語言。遊戲從一種語言載入語音音訊，同時顯示另一種語言的文字。

## 還原

隨時點擊**還原備份**即可撤銷所有變更，恢復到原始狀態。

## 遊戲更新後

遊戲更新可能會重設你的語言設定。如果發生這種情況，只需重新套用相同的設定 — 只需幾秒鐘。

## 常見問題

**問：需要先在 Steam 中下載語言套件嗎？**
答：是的。在 Steam 中右鍵遊戲 → 內容 → 語言，確保語音和文字語言都已下載。

**問：安全嗎？**
答：工具僅修改文字資源檔案（`StringTables` 中的 `.zip`）。不會觸及可執行檔、存檔或反作弊系統。所有變更都會備份，可隨時還原。

**問：會被封鎖帳號嗎？**
答：本工具不修改遊戲玩法、網路資料或反作弊元件，僅變更本機文字檔案。但使用風險自負。
