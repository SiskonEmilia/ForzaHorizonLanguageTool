# FH Language Combo Tool

FH Language Combo Tool은 Forza Horizon 5 / 6 (Steam, PC)에서 음성과 텍스트에 서로 다른 언어를 사용할 수 있게 해주는 도구입니다.

예시: 한국어 텍스트 + 영어 음성, 또는 한국어 텍스트 + 일본어 음성.

## 다운로드

[Releases](https://github.com/SiskonEmilia/ForzaHorizonLanguageTool/releases) 페이지에서 최신 버전을 다운로드하세요.

- **포터블**: `FH-Language-Combo-Tool-Portable.exe` — 설치 없이 바로 실행
- **설치 프로그램**: `FH-Language-Combo-Tool-Setup.exe` — 시스템에 설치

## 빠른 시작

1. 도구를 다운로드하고 실행
2. 면책 조항에 동의
3. 도구가 FH5/FH6 Steam 설치를 자동 감지
4. **음성 언어** 선택 — 듣고 싶은 언어 (캐릭터 음성)
5. **텍스트 언어** 선택 — 보고 싶은 언어 (메뉴, 자막)
6. **적용** 클릭
7. 작업 확인
8. 게임 실행 — 완료!

## 작동 원리

도구는 게임의 `StringTables` 디렉토리에서 텍스트 언어 파일을 음성 언어 파일 위치에 복사하고, 게임 시작 언어를 선택한 음성 언어로 자동 설정합니다. 게임은 한 언어의 음성 오디오를 로드하면서 다른 언어의 텍스트를 표시합니다.

## 복원

**백업 복원**을 클릭하면 언제든지 모든 변경 사항을 되돌리고 원래 상태로 복원할 수 있습니다.

## 게임 업데이트 후

게임 업데이트로 언어 설정이 초기화될 수 있습니다. 이 경우 동일한 설정을 다시 적용하면 됩니다 — 몇 초면 완료됩니다.

## 자주 묻는 질문

**Q: Steam에서 언어 팩을 먼저 다운로드해야 하나요?**
A: 네. Steam에서 게임 우클릭 → 속성 → 언어에서 음성 언어와 텍스트 언어가 모두 다운로드되어 있는지 확인하세요.

**Q: 안전한가요?**
A: 도구는 텍스트 리소스 파일(`StringTables`의 `.zip`)만 수정합니다. 실행 파일, 세이브 파일, 안티치트에는 전혀 영향을 주지 않습니다. 모든 변경 사항은 백업되며 되돌릴 수 있습니다.

**Q: 밴 당할 수 있나요?**
A: 이 도구는 게임플레이, 네트워크 데이터, 안티치트 구성 요소를 수정하지 않습니다. 로컬 텍스트 파일만 변경합니다. 다만, 사용은 본인 책임입니다.
